# Stage A24 — Automation Engine

Добавлен `/automations`: no-code правила для реакции на отзывы и reputation signals.

## Триггеры

- новый отзыв;
- 75% SLA;
- SLA просрочен;
- согласование ждёт более 4 часов;
- рост причины негатива >= 50%.

## Условия

- диапазон рейтинга;
- площадки;
- причины негатива.

## Действия

- создать связанную задачу;
- уведомить руководителя;
- отправить черновик на согласование;
- передать отзыв Бизнес Щит.

## Защита от дублей

Каждая комбинация `rule + trigger + review` фиксируется в execution ledger. Изменение review после действия может породить новое browser event, но повторное выполнение того же правила блокируется. При ошибке claim освобождается и действие можно повторить.

## Runtime

Automation Runtime находится в `PortalLayout`, поэтому сценарии не зависят от того, открыт ли сейчас `/reviews`. Проверка SLA выполняется раз в 5 минут только в видимой вкладке. Review mutations запускают проверку сразу.

## Production

В production выполнение правил должно постепенно переехать на backend/job queue. Frontend runtime — функциональный fallback и средство разработки. Критичные действия должны быть идемпотентны на сервере.
