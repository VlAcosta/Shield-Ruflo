# Admin Stage A3 — Visual Redesign & Motion System

Этот этап полностью перерабатывает визуальный язык административной части без изменения существующей бизнес-логики.

## Что изменено

### AdminLayout
- новый premium dark sidebar;
- новый topbar с более плотной типографикой;
- Ctrl/Cmd + K фокусирует поиск;
- управление результатами поиска стрелками + Enter;
- системный LIVE-индикатор;
- обновлённые уведомления и профиль администратора;
- более выразительные hover / active / focus состояния;
- обновлённый PIN overlay;
- адаптивный compact-sidebar сохранён.

### Dashboard
- новый Command Center intro;
- полностью переработанные KPI-карточки;
- собственные SVG-иконки метрик;
- анимированная прорисовка revenue chart;
- более выразительный тарифный donut;
- улучшены списки клиентов, тикетов и менеджеров;
- новая визуализация выручки команды;
- staggered enter-анимации без тяжёлого blur.

### Clients
- новый intro-блок клиентской базы;
- показатель доли активной базы;
- переработанные KPI;
- новый toolbar и визуальная система фильтров;
- premium table row interactions;
- улучшены create/edit dialogs;
- обновлена детальная карточка клиента;
- анимированы KPI, timeline, activity chart и tickets.

## Motion principles

Анимации используют преимущественно:
- opacity;
- transform;
- SVG stroke-dashoffset;
- короткие width transitions для bar charts.

Не используются постоянные backdrop-filter / blur-анимации на рабочих карточках, чтобы визуальные эффекты не ухудшали производительность.

Поддерживается `prefers-reduced-motion: reduce`.

## Что не изменено
- API-контракты;
- localStorage fallback;
- роуты;
- клиентская модель;
- логика создания/редактирования клиентов;
- PIN-логика.
