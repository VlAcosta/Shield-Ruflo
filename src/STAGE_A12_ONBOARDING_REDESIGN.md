# Stage A12 — Onboarding redesign

## Что изменено

- Onboarding вынесен из большой страницы в отдельный feature `features/onboarding`.
- Полностью переработан первый шаг регистрации организации.
- Добавлен сценарий: ИНН → поиск → карточка найденной организации → подтверждение.
- Добавлен ручной ввод реквизитов на случай недоступности lookup API.
- Добавлено сохранение черновика onboarding в localStorage, поэтому обновление страницы не сбрасывает прогресс.
- Полностью переработан шаг интеграций: карточки площадок, переключатели, ссылки и счётчик выбранных подключений.
- Полностью переработан шаг безопасности: цифровая PIN-клавиатура, клавиатурный ввод и настройка автоблокировки.
- После завершения показывается короткое success-состояние, затем открывается Dashboard.
- Маршрутный guard из Stage A11 сохранён: доступ к кабинету открывается только после всех трёх шагов.

## Lookup организации

Frontend использует `REACT_APP_API_BASE` и вызывает:

`POST {REACT_APP_API_BASE}/company/lookup`

Тело:

```json
{ "inn": "7701234567" }
```

Ожидаемый ответ:

```json
{
  "source": "ФНС / ЕГРЮЛ",
  "company": {
    "type": "ul",
    "title": "ООО «Название»",
    "shortTitle": "ООО «Название»",
    "inn": "7701234567",
    "kpp": "770101001",
    "ogrn": "1027700123456",
    "address": "г. Москва",
    "status": "Действующая организация",
    "registrationDate": "17.08.2025"
  }
}
```

Если `REACT_APP_API_BASE` отсутствует, используется явно обозначенный demo lookup:
- `7701234567` — ЮЛ;
- `772345678012` — ИП.

Demo данные не выдаются за реальные сведения ФНС.
