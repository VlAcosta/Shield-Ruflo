# API onboarding

## POST `/company/lookup`

Назначение: получить реквизиты организации по ИНН через backend-интеграцию с источником ЕГРЮЛ/ФНС.

Request:

```json
{
  "inn": "7701234567"
}
```

Response:

```json
{
  "source": "ФНС / ЕГРЮЛ",
  "company": {
    "type": "ul",
    "title": "ООО «Название»",
    "shortTitle": "ООО «Название»",
    "inn": "7701234567",
    "kpp": "770101001",
    "ogrn": "1027700123456",
    "address": "г. Москва",
    "status": "Действующая организация",
    "registrationDate": "17.08.2025"
  }
}
```

Frontend timeout: 6.5 seconds.

Не рекомендуется обращаться к внешнему сервису ФНС напрямую из браузера. Lookup должен проходить через backend приложения, где можно реализовать кэш, rate limits, нормализацию ответа и аудит запросов.
