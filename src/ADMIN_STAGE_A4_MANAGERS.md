# Admin Stage A4 — Managers

Раздел «Менеджеры» переработан в полноценную CRM-зону команды.

## Что добавлено

- отдельный route `/admin/managers`;
- активный пункт «Менеджеры» в AdminSidebar;
- KPI команды: всего, активных, средний рейтинг, выручка;
- поиск и фильтр по статусу;
- список менеджеров с загрузкой, рейтингом, клиентами и тикетами;
- детальная карточка выбранного менеджера;
- динамика эффективности на лёгком SVG-графике;
- клиентский портфель менеджера;
- переход в карточку клиента;
- переназначение клиента другому менеджеру;
- добавление нового менеджера;
- редактирование профиля менеджера;
- localStorage fallback;
- API-ready service layer;
- responsive layout;
- skeleton, empty, error и toast states;
- prefers-reduced-motion;
- новые motion patterns без тяжёлых blur/filter анимаций.

## Производительность

Основные анимации используют `transform`, `opacity` и `stroke-dashoffset`.
Длинные строки менеджеров используют `content-visibility: auto`.
Никакие сторонние chart/UI библиотеки не добавлялись.

## Связь с клиентами

Финансовые показатели менеджера рассчитываются по фактически назначенным клиентам из Admin Clients service. Поэтому переназначение клиента сразу меняет клиентский портфель и месячную выручку менеджеров.
